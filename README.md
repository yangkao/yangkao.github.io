# Yangkao

一个记录生活、学习与技术实践的个人博客。

**站点入口：[https://yangkao.github.io/](https://yangkao.github.io/)**

这里收录一路走来的实践心得、日常片段、随想、读书笔记与旅行见闻。文章通过分类与标签整理，可以在站内搜索和阅读。

## 站点内容

- **文章**：普通图文记录，以及带有独立布局和动态交互的定制文章。
- **日历**：以日期组织的公开待办、纪念日与大事纪。
- **项目**：项目概述、缩略图与多个相关入口。
- **首页**：随机名句、音乐播放与个人链接。

界面使用浅色背景、青绿配色与玻璃风控件，并加入圆点背景和柔和的交互过渡。

## 关于本仓库

本仓库保存博客的公开网站文件，通过 GitHub Pages 发布。网站仅包含允许公开的内容；私密文章、原始内容库及管理者凭据不在本仓库中。

公开页面采用静态部署，部分动态功能由独立接口提供。第三方组件的许可声明随站点保留在 `licenses/` 目录。

管理者可在不同设备通过 GitHub 验证身份，继续在原有博客中浏览私密文章、日历与项目。私密内容经受保护的接口读取，不写入本公开仓库；普通访客无需登录。
